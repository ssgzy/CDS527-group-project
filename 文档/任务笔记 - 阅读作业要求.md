## Task 1：System Development（30%）
- 任务对象：老师会给一份 business textual dataset，并规定统一的数据切分方式和 evaluation metric
- 任务目标：开发一个表现尽可能好的文本分类决策支持系统
- 明确要求：
  - 建 baseline model，示例是 logistic regression
  - 比较多种数据分析模型，例如 gradient boosting tree、decision tree 等
  - 比较多种词向量或 embedding 方法，例如 BERT、GloVe、Word2Vec 等
  - 为不同模型调超参数，并报告最佳分数
  - 做数据统计与可视化，例如 bar chart、line graph、word cloud、分布、集中趋势、离散程度、相关性、标准差等
  - 探索提升 baseline 的不同方法，评分会看方法的新颖性、方法多样性、实现难度和改进效果
- 工具限制：
  - 代码必须主要基于 PySpark
  - 仅在极少数特殊情况下可少量使用标准 Python，否则会扣分
- 提交要求：
  - 提交一个 Jupyter Notebook
  - Notebook 里需要覆盖上述 1 到 5 点的代码实现
  - 另附一个短表格和或少于 300 字的说明，概述尝试过的模型、超参数、可视化方法、分数等
- 关键约束：
  - 整个项目必须保持同一套 data split 和 evaluation metric，不允许中途更改

## Task 2：Case Study（10%）
- 老师会给每组一个公司案例，候选公司包括 Airbnb、Amazon、Apple、BBC、Facebook、Fitbit、Google、Ralph Lauren、Twitter、Walmart 等
- 你们需要写的内容：
  - 公司背景描述
  - 如何理解并处理该公司的业务问题和或数据
  - 提出的 Big Data 解决方案
  - 对解决方案做批判性评估
- 题目建议考虑的角度：
  - Big Data 的 5Vs
  - 数据类型与数据格式
  - 公司采用 Big Data 方案的业务动机
  - 可以使用哪些分析方法，例如 A/B testing、heat map、clustering、text analysis
  - 用什么 KPI 来评估，例如 SMART
