## 数据预处理约定

| 项目 | 值 | 说明 |
|------|----|------|
| 使用文件 | `smile-annotations-final.csv` | 1299 行原始数据 |
| PySpark 读取参数 | `multiLine=True, quote='"', escape='"'` | 部分 tweet 含换行符，必须开启 multiLine |
| 去重策略 | `dropDuplicates(['text'])` | 去掉 1 条 text 完全相同的重复行（tweetid 不同），保留后有效样本 **1298 行** |
| 标签类型 | `float`（0.0–4.0） | PySpark inferSchema 后为 float，标签映射见 [[数据说明]] |

## 数据切分

| 字段 | 值 | 说明 |
|------|----|------|
| 切分方式 | Label-aware near-stratified split | 通过 `sampleBy` 按标签近似保持类别比例 |
| 训练集比例 | 约 80%（1032 行） | sampleBy fraction=0.8 |
| 测试集比例 | 约 20%（266 行） | df.subtract(train) |
| Random seed | **42** | 固定，全程不变 |
| PySpark API | `df.sampleBy('emotions', fractions={k:0.8 for k in labels}, seed=42)` | |

## 评价指标

| 字段 | 值 | 说明 |
|------|----|------|
| **主指标** | **macro-F1** | 对所有类别等权平均，适合多分类 + 类别不平衡场景 |
| 辅助指标 1 | weighted-F1 | 按各类样本数加权，参考用 |
| 辅助指标 2 | accuracy | 仅作参考（因严重不平衡，不作为主要比较依据） |
| 计算方式 | sklearn `f1_score(average='macro')` | PySpark 内置 `MulticlassClassificationEvaluator` 的 `f1` 为 weighted-F1；macro-F1 通过 `.toPandas()` 后用 sklearn 计算 |

### 选择 macro-F1 的理由
- 数据中 happy 类占 89.1%，accuracy 会因此虚高
- macro-F1 对每个类别（含 disgust 的 13 条）给予同等权重，能更真实反映模型对少数类的识别能力
- 学术界对不平衡多分类任务的标准选择
- 当前 sanity check 也验证了：
  - majority baseline accuracy 很高，但 macro-F1 很低
  - label shuffle 后结果退回多数类水平
  - `class_weight` / `weightCol` 后 macro-F1 明显提升
