# 问题与坑点

## 当前已发现问题

### 1. 截止日期存在明显矛盾
- 文档标题：`CDS527 Big Data Analytics 2025-2026 Term2`
- 提交说明：`30-April-2025 23:59 HK time`
- 判断：这个日期很可能是旧模板残留或笔误，必须以 Moodle 或老师最新通知为准

### 2. 提交数量描述不一致
- 文档文字写的是 `submit three files`
- 但实际列出的组内提交物有 4 项：
  - Notebook
  - Report
  - PPT
  - Separate GAI declaration sheet
- 另外还要求每位学生再单独上传一份 `work distribution` 文件

### 3. 当前关键输入只部分齐全
- 本地目录中已经存在：
  - `Google.docx`
  - `SMILE Twitter Emotion Dataset.docx`
  - `smile-annotations-final.csv`
- 但 Task 1 仍缺少老师明确指定的：
  - 标准 data split
  - evaluation metric

### 4. 数据说明与实际 CSV 规模不一致
- `SMILE Twitter Emotion Dataset` 说明文档写的是 `3,085 tweets`
- 本地 `smile-annotations-final.csv` 实际只有 `1299` 行数据
- 当前判断：
  - 可能是子集版本
  - 可能有清洗或过滤
  - 也可能当前 CSV 不是老师最终指定版本

### 5. PySpark 是硬性要求
- 文档明确说 PySpark 必须是主要开发工具
- 过度依赖标准 Python 会扣分
- 后续做实验时必须持续检查实现方式，避免 notebook 最终呈现不符合要求

### 6. 当前数据类别极不平衡
- `happy` 类远高于其他类别
- 如果只看 accuracy，结果可能具有误导性
- 后续必须结合老师指定指标来设计实验汇报

### 7. PySpark 3.1.2 与 Java 版本冲突（2026-03-31 发现）
- 系统默认 JAVA_HOME 指向 conda 内 Java 17（Zulu）
- PySpark 3.1.2 与 Java 17 存在 module access 限制（`InaccessibleObjectException`），SparkSession 无法启动
- **解决方案**：启动 PySpark 前必须指定 Java 11：
  `export JAVA_HOME=/Library/Java/JavaVirtualMachines/amazon-corretto-11.jdk/Contents/Home`
- 已安装：Amazon Corretto 11（/Library/Java/JavaVirtualMachines/）

### 8. PySpark 读取 CSV 行数错误（2026-03-31 发现）
- 默认 `spark.read.csv(header=True, inferSchema=True)` 读取后得到 1355 行（含 97 个 null emotions）
- 原因：部分 tweet 正文含换行符，默认读取将其拆成多行
- **解决方案**：必须加 `multiLine=True, quote='"', escape='"'`，读取后行数正确为 1299 行，零 null

- 从一开始就以 PySpark 为主组织代码结构和实验记录
