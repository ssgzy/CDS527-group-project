## 文本噪声特征

| 特征 | 数量 | 占比 |
|------|------|------|
| 含 URL | 591 | 45.5% |
| 含 @提及 | 1299 | 100.0% |
| 含 #标签 | 479 | 36.9% |
| 含非 ASCII 字符（emoji 等） | 103 | 7.9% |
| 含 `&amp;` HTML 实体 | 114 | 8.8% |

> **100% 含 @提及**：这是 Twitter 数据的典型特征（用户互动 @ 博物馆账号）。预处理时需决定是否去除 @用户名。
> URL 占 45.5%，建议统一替换或去除，避免污染特征空间。

## 当前已知问题
1. **数据规模不一致**：说明文档写 3,085 条，实际 CSV 为 1,299 行（原因未确认，可能是子集）
2. **PySpark 读取需 multiLine=True**：否则含换行 tweet 会被拆成多行，导致脏数据
3. **类别极不平衡**：happy 占 89.1%，不能以 accuracy 作为主指标

## 对 Task 1 的影响
- 预处理需明确处理 URL、@提及、#标签、HTML 实体
- 建模指标必须使用 macro-F1（见 [[实验协议]]）
- 少数类（尤其 disgust 13 条）在 test set 中仅 3 条，per-class 分析需注意样本量
